## 5. 关键交互说明

### 5.1 依赖三分类：语义与文案（重点）

数据源以 **Modrinth 版本级** `dependency_type` 为准，四类一一对应：

| 分类 | API 值 | 语义 | 界面文案（建议） | 是否给安装按钮 |
|---|---|---|---|---|
| ① 必须装 | `required` | 缺了此版本无法正常工作 | **「必须安装」**；未装时行尾「安装」；已装显示「✓ 已安装」 | ✅ 是（缺失时） |
| ② 已内嵌 | `embedded` | 作者已把该依赖打包进本文件，用户**无需**再装 | **「作者已打包，无需安装」**（灰字、可折叠） | ❌ 否 |
| ③ 选装 | `optional` | 装了有增强，不装也能用 | **「可选安装」**；已装打勾 | ✅ 是（未装时） |
| ④ 冲突 | `incompatible` | 与本版本冲突、不能共存 | 见 §5.3 | ❌ 否 |

补充规则：
- `file_name` 存在而 `project_id` 为空（外部依赖，常见于整合包）→ 只显示文件名 +「外部依赖，需自行准备」，不给安装按钮。
- 依赖名称用 `project_id` 后台换真实标题（现有 `populateDeps` 已有此逻辑，保留）；拉不到标题就显示 ID，不阻塞界面。
- 双源术语对齐（P1-1 用）：CF `RequiredDependency→①`、`EmbeddedLibrary`/`Include→②`、`OptionalDependency→③`、`Incompatible→④`、`Tool`→忽略。

### 5.2 提示的展示位置

**推荐方案 A（最小变更，建议采用）**：保留现有详情弹窗 §4「前置依赖」区（位于 §5「版本列表」**上方**），改为**版本联动**——
- 默认展示「当前游戏版本推荐版本」的依赖；
- 用户点击 / 展开某个版本行时，§4 立即切换为该版本的三分类提示；
- 无依赖时板块连同标题一起隐藏（现有 `visible/managed` 绑定已实现）。

备选方案 B：每个版本行内展开一个小的依赖条（信息更贴近版本，但 243 行会重复渲染、改动大）。
> 两方案请主理人确认（Q2）。PRD 默认按 A 写。

### 5.3 incompatible / 冲突依赖的处理建议

**建议：标注冲突，但不静默阻断安装。**

- 详情弹窗内以红色警告条显示「⚠ 与以下项目不兼容，同时安装可能进不去游戏：<项目名>」；
- 若该冲突项目**本地已安装**，点「安装」时二次确认：「检测到已装 X，与本模组冲突，仍要安装？」；
- 不把冲突项混进「必须装 / 选装」列表（避免用户误装）；
- 备选：完全不显示冲突项（信息更少但界面更干净）。
> 请主理人在 Q3 拍板「标注冲突」还是「不显示」。

### 5.5 三类内容的安装目标路径（相对 `Platform.minecraftDir()` = `GBL/.minecraft`，全局共享）

| 类型 | 目标目录 | 落盘形态 | 来源 | 「启用」语义 |
|---|---|---|---|---|
| 资源包 | `.minecraft/resourcepacks/` | `.zip` 文件（或解压后目录） | Modrinth `resourcepack` / CF `classId=12` | 启动器侧 `.disabled` 改名；游戏内启用仍需玩家在选项里选（P1-4 自动写 `options.txt`） |
| 光影 | `.minecraft/shaderpacks/` | `.zip` 文件 | Modrinth `shader` / CF `classId=6552` | 同上；**需 OptiFine 或 Iris 才生效**，安装时给一句提示 |
| 世界 | `.minecraft/saves/<世界名>/` | **目录**（zip 需解压，不是丢一个文件） | CF `classId=17` 待确认（Q1）；Modrinth **无 world 类型** | 世界没有「启用开关」，只有「是否出现在游戏存档列表」；建议不提供启停，只提供删除 / 打开文件夹 / 本地导入（Q5） |

### 5.7 OptiFine 的组合关系与安装入口

事实依据：HMCL 文档与社区共识——OptiFine 是**独立加载器/独立版本**（官方 installer 改写客户端 jar 或导出为 jarmod），与 Forge 大多数版本可共存（需同 MC 版本且版本匹配），与 Fabric 原生不兼容（需 OptiFabric 桥接）、Quilt 无解。

| 组合 | 0.8.7 行为（建议） |
|---|---|
| 原版 + OptiFine（独立版本） | ✅ 主路径，P0 支持 |
| OptiFine + Forge | ⚠️ 允许，但给「需匹配同 MC 版本的兼容构建，部分组合会崩」提示；不做自动兼容保证 |
| OptiFine + Fabric / Quilt / LegacyFabric | ❌ 明确不兼容提示，并给替代建议「Iris Shaders + Sodium」（正好衔接本次光影 tab） |
| OptiFine 作为普通 mod 丢进 `mods/` | 不自动做；如用户手动放，不拦 |

**定位**：OptiFine 作为**独立加载器**加入加载器体系（与现有 `LoaderType` 的元数据型 / 安装器型并列第三类「jarmod/改写客户端 jar 型」），不复用 Forge installer 流程。

**安装入口（建议三处，P0 至少前两处）**：
1. 下载页「加载器」tab：新增 OptiFine 卡片 + 版本下拉（默认最新稳定版）；
2. 「安装新游戏」弹窗：勾选 OptiFine（与 Fabric/Forge 并列，互斥校验按上表）；
3. 游戏管理页「自动安装」对已装版本补装（建议 P1-5）。
